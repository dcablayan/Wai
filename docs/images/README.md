# Dashboard Screenshots

This directory is the home for Streamlit dashboard screenshots that are
linked from the project [README](../../README.md). Suggested captures
(all from `make demo` followed by `make dashboard`):

1. `01_overview.png` — Overview tab, station map and time series.
2. `02_forecasts.png` — Forecasts tab, 1-step online forecast plus the
   90 % conformal interval band, with the horizon selector visible.
3. `03_model_comparison.png` — Model Comparison tab, full multi-horizon
   table.
4. `04_alerts.png` — Alerts tab with the **train-window threshold** caption
   visible (proves the threshold is anchored, not display-derived).
5. `05_uncertainty.png` — Uncertainty tab with overall / event / non-event
   coverage tiles.
6. `06_benchmark.png` — Benchmark tab, prototype RMSE table.

Until real screenshots are added, the README links the directory rather
than a specific file to avoid broken images in GitHub renderings.
